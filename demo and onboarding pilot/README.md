# Demo and Onboarding Pilot

Self-contained package for the KFL Aviation DMS user-training workshop and restricted onboarding pilot. Assembled from the repository docs and the controlled KFL manuals.

No emojis. Controlled manuals are read-only. This package is training material; it does not authorize accounts, invites, commits, or deployment.

## How to run the workshop

1. Open the programme (01-Training-Programme.md) and confirm the facilitator and role leads.
2. Open the decks in a browser. Each deck supports arrow-key navigation, a slide counter, and remembers the last slide.
3. Follow the session order in the programme; each session names its deck and supporting document.
4. Use the controlled manuals in manuals/ for the live reading demonstration.
5. Capture actions and the go/no-go date in the participant workbook (documents/WORKSHOP-PARTICIPANT-WORKBOOK.md).

## Decks

Fixed 1920x1080 slides, illustration-led (text kept to a minority of each slide), keyboard navigation, print-friendly. Palette and typography match the DMS product (navy, brand blue, Inter).

Offline distribution: each deck is also exported to PDF (one slide per page, 1920x1080) alongside the HTML — `decks/01-Welcome-and-Overview.pdf`, `decks/02-Role-Workspaces-and-Compliance.pdf`, `decks/03-Administration-and-Operations.pdf`. The HTML versions remain the primary source; the PDFs are snapshots for printing and offline viewing.
