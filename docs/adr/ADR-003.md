# ADR-003: Caddy on Bastion for TLS Termination

## Status
Accepted

## Date
2026-11-12

## Context
Production traffic to `roc.kfl.ke` requires HTTPS termination. The OCI production instance `10.20.1.69` has no public IP and is reachable only via bastion `145.241.152.126`. Caddy must run on the bastion as the TLS entry point and reverse-proxy to the production instance.

## Decision
Run Caddy on the bastion host `145.241.152.126` with:
- `roc.kfl.ke` → production backend `10.20.1.69:8000` (API routes) and frontend `10.20.1.69:8080` (all other routes)
- `stage.kfl.ke` → staging backend `10.20.4.234:8001` and frontend `10.20.4.234:8081`
- Security headers: HSTS, X-Content-Type-Options, X-Frame-Options, Referrer-Policy, Permissions-Policy, Content-Security-Policy
- `DMS_TRUSTED_FRONTEND_IP=145.241.152.126/32` so the backend honors `X-Forwarded-For` only from the bastion

## Rationale
- **No public IP on production**: The OCI instance is private; bastion is the only publicly reachable host with a valid Let's Encrypt certificate.
- **Centralized TLS**: Caddy on bastion obtains and renews certificates automatically; production backend never handles TLS directly.
- **Security headers**: Applied at the edge, consistent across both environments.
- **Trusted proxy**: The backend accepts `X-Forwarded-For` only from the bastion IP, preventing IP spoofing from other sources.

## Consequences
- **Positive**: Production backend remains private (no public port exposure), automatic certificate management, security headers at edge.
- **Negative**: Bastion is a single point of failure for production HTTPS; Caddy reload required on bastion for configuration changes.
- **Mitigation**: Bastion is hardened; Caddy config is version-controlled in `Caddyfile.bastion`.

## Alternatives Considered
- **Caddy on production instance**: Rejected — production has no public IP and cannot terminate public HTTPS.
- **NGINX on bastion**: Rejected — Caddy's automatic ACME certificate management is simpler for this deployment.

## Review
Review if bastion availability requirements change or if a load balancer is introduced.
